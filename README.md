# Pakistan Truck Driver Tycoon

An immersive Godot 4 mobile game where you manage a trucking business in Pakistan. Buy trucks, deliver cargo, and expand your empire.

## 🎠 Features

- Buy and upgrade trucks in the garage
- Deliver cargo across Pakistan
- Manage your finances and level up
- Mobile-optimized with Godot 4
- Portrait orientation support

## 🔾 Tech Stack

- Framework: Godot 4
- Language: GDScript
- Platform: Mobile (Android)

## 📠 Getting Started

1. Install Godot 4 from [godotengine.org](https://godotengine.org/)
2. Import this project into Godot
3. Press F5 to run
